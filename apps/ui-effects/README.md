# Atelier — Libraries.dev UI effects

Dark gallery demo of all five [Libraries.dev](https://libraries.dev) React effect packages from [Jakub Antalik’s announcement](https://x.com/Jakubantalik/status/2095551141367173608).

1. `border-beam`
2. `thinking-orbs`
3. `liquid-gooey`
4. `metal-fx`
5. `img-fx` (peer: `three`)

## Run

```bash
cd apps/ui-effects
bun install
bun run dev
```

Open the printed local URL (Vite, usually `http://localhost:5175`). Production path is `/ui-effects/`.

## What to try

- **Beam** — swap size/color, drag strength, pause
- **Orbs** — pick a thinking state and avatar vs inline size
- **Gooey** — split/fold the plus menu
- **Metal** — chromatic / silver / gold on the upgrade pill
- **Image** — watch the mosaic reveal, or trigger reveal / regenerate
