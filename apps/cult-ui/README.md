# Kiln — Cult UI gallery

Dark stage demo of six free MIT [Cult UI](https://cult-ui.com) components, vendored from the open [nolly-studio/cult-ui](https://github.com/nolly-studio/cult-ui) registry. Source pick: [Notion Inbox](https://app.notion.com/37189ff326a1816db52fcacf29a21641).

1. Shift Card
2. Texture Button
3. Texture Card
4. Expandable
5. Family Button
6. Dock

Not Cult Pro.

## Run

```bash
cd apps/cult-ui
bun install
bun run dev
```

Open the printed local URL (Vite, usually `http://localhost:5177`). Production path is `/cult-ui/`.

## What to try

- **Shift Card** — hover to lift the still and reveal the share tray
- **Texture Button** — press each glaze; the last press updates
- **Texture Card** — fill the slip and continue
- **Expandable** — click Design Sync to grow the meeting
- **Family Button** — open the plus and pick a glaze
- **Dock** — sweep icons, click a tile to bounce
